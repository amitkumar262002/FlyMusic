## 🎨 **Color Usage Guide**

### Primary Actions:
- Use `PrimaryPurple` for primary buttons
- Use `PrimaryCyan` for secondary actions
- Use `AccentMagenta` for highlights

### Backgrounds:
- Use `BackgroundDark` for main background
- Use `SurfaceDark` for elevated surfaces
- Use `CardDark` for cards and containers

### Text:
- Use `TextPrimary` for main content
- Use `TextSecondary` for descriptions
- Use `TextTertiary` for hints
